3반 TALK V4.3

추가 기능
1. 교사 화면: 학생이 보낸 읽지 않은 1:1 메시지가 있으면 학생 이름 옆에 NEW 표시
2. 교사만 개별 메시지 삭제 가능 (학생 메시지 / 교사 메시지 / 공지 모두)
3. 교사만 특정 학생의 1:1 대화 전체 삭제 가능
4. 학생에게는 삭제 권한 없음
5. 학생 계정 삭제 기능은 넣지 않음
6. V4.2의 전체채팅 제거 / 공지사항 / 1:1 구조 유지

업데이트 순서
① Supabase > SQL Editor에서 V4.3-update.sql 전체 실행
② GitHub 기존 파일 위에 이 ZIP의 파일을 덮어쓰기
③ Commit changes
④ Vercel 자동배포 완료 후 Ctrl+F5
⑤ 교사/학생 테스트 계정으로 NEW 표시와 삭제 기능 확인

주의
- V4.3-update.sql은 기존 학생 계정이나 기존 메시지를 지우지 않습니다.
- 개별/전체 삭제 기능으로 삭제한 메시지는 DB에서도 실제 삭제되며 복구되지 않습니다.
